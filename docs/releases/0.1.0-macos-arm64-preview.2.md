# Branch 0.1.0 — macOS ARM64 Preview 2

This preview adds watch-room hosting directly inside the Branch app. The host
shares playback state over a TLS-protected connection; every participant must
already have the same video file locally. Branch checks the complete file
using SHA-256. Video files are not sent between participants.

## Download

- `Branch-macos-arm64.zip` — Apple silicon app bundle, requires macOS 11.0 or
  newer.
- SHA-256: `c4642178340dc7ddf50fc4bf0d826f36588402606db3b3a9ca345cb834455863`

Follow [the installation guide](../development/INSTALL-macOS-ARM64.md).

## Known limits

- This is an experimental build. Device acceptance and cross-network hosting
  have not been verified.
- The host attempts to configure TCP port 8787 with UPnP and needs a reachable
  public IPv4 address. CGNAT or router restrictions can prevent guests on other
  networks from connecting.
- The app is ad-hoc signed and is not notarized by Apple. Gatekeeper may block
  the first launch; see the installation guide.
- The native dependency/license inventory is incomplete, and distribution
  obligations have not received separate legal review.
